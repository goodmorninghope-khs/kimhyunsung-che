# 글 종류별 형식 지도 (writing-form-map)

같은 소재라도 글의 종류가 다르면 형식이 달라야 한다. 이 스킬은 요청을 받자마자 '어떤 글인가'를 판별하고, 형식을 먼저 제안한 뒤 알맞은 스킬로 넘긴다.

## 형식 지도

| 종류 | 독자와 자리 | 분량 | 골격 | 연결 스킬 |
|---|---|---|---|---|
| 신문 칼럼 | 출근길 독자, 1분 판단 | 1,800~2,500자 | 시사 리드→규정→예측→갈림길→제목 반복 | golmok-diagnosis |
| 기고·오피니언 | 정책 관심층 | 3,000~5,000자 | 규정·예측 + 근거 강화, 반론 정면 대응 | golmok-diagnosis |
| 페이스북 글 | 스크롤 중인 지인·지지층 | 800~1,500자 | 15자 안팎 첫 줄, 한 호흡 한 줄, 다짐이나 2행 대구 → PS → 해시태그로 맺음 | golmok-writer 4장 |
| 뉴스레터 '뜻땀때 소포' | 구독자 | 1,500~3,000자 | 합쇼체 머리말 → -다체 본문 → PS | golmok-writer 4·16장 |

| 극본·기획안 | 제작자·시청자 | 형식별 | 로그라인·주제·하이 콘셉트 | drama-writer |

### 듣는 글 규칙 (연설·강연)
- 한 문장 한 호흡. 숫자는 3개 이내, 반올림해서 기억되게.
- 핵심 문장은 두 번 말한다. 읽는 글에서는 군더더기지만 듣는 글에서는 닻이다.
- 화자의 입에 맞춘다. 화자가 쓰지 않는 단어는 빼고, 낭독해서 걸리는 곳을 고친다.

## 적극 제안의 방식

1. **판별**: 요청에서 독자·자리·분량을 읽는다. 분명하면 "○○ 형식으로, ○○자, ○○ 골격으로 갑니다" 한 줄을 밝히고 바로 시작한다.
2. **애매하면 2안**: 예) "칼럼(규정·예측형)과 에세이(이야기형) 중 어느 쪽인가요?" 한 번만 묻는다.
3. **더 나은 형식이 보이면 말한다**: 요청한 형식보다 소재에 더 맞는 형식이 있으면 이유 한 줄과 함께 제안한다. 결정은 사용자가 한다.
4. **파생 제안**: 글을 마친 뒤 같은 소재로 이어질 형식 하나를 제안한다.
   - 칼럼 → 페이스북 요약 → 카드뉴스 → 강연 한 꼭지 → 책의 한 장
   - 기고 → 페북 액자(머리말 + 본문 + PS) → 소포 → 시그널 BIG Q (문장은 복제하지 않고 지면마다 다시 쓴다)
   - 현장 에세이 → 규정·예측 칼럼으로 재구성
   - 예측이 담긴 글 → 검증 시점에 '예측 복기' 글

문장과 목소리는 어느 형식이든 golmok-writer를 따른다. 발행물마다 김현성체를 얼마나 얹을지는 golmok-writer 16장의 표가 정한다.
