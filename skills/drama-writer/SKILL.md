# 극작 스킬 (drama-writer)

출발점: 이기원 작가(〈하얀 거탑〉〈제중원〉)의 작법서 『당신은 더 잘 쓰게 된다』(오늘산책)를 소개한 서평에서 뽑은 원리를 작업 순서로 재구성했다. 원문 문장을 옮기지 말고, 아래 원리를 도구로 쓴다.

핵심 전제: 좋은 드라마의 원료는 좋은 대본이다. 글쓰기에 정답 공식은 없지만, 작가가 스스로 만든 '작업 공식'은 있다. 이 스킬은 그 공식을 체크리스트로 쓴다.

---

## 1단계. 기획 — 세 가지를 먼저 쓴다

본문을 쓰기 전에 아래 세 가지를 각각 한 덩어리로 써서 사용자에게 먼저 보여 준다. 셋이 서지 않으면 장면을 쓰지 않는다.

1. **로그라인** — 세계관과 갈등을 한 문장으로.
   - 형식: [결핍·처지가 있는 주인공]이 [목표]를 위해 [가장 강한 장애물]과 맞서는 이야기.
   - 점검: 이 한 문장만 듣고 '그래서 어떻게 되는데?'가 나오는가.
2. **주제** — 이야기가 끝난 뒤에도 남아야 할 단 하나.
   - 한 문장, 교훈조가 아니라 질문이나 깨달음의 형태로.
   - 점검: 모든 주요 장면이 이 주제를 밀거나 비트는가. 아니면 덜어낸다.
3. **하이 콘셉트** — 팔리게 만드는 설정 한 줄.
   - 'A인데 B' 구조의 낯선 결합, 혹은 '만약 ~라면?'으로 시작하는 질문.
   - 점검: 편성 담당자·투자자가 10초 안에 그림을 떠올리는가.

## 2단계. 타깃의 욕망 — '특별한 공통분모'를 찾는다

작가의 일은 타깃층의 욕망을 정확히 짚고 그것을 이야기로 보여 주는 것이다. 시청자의 욕망과 드라마의 설정이 단단히 묶이면 승부가 난다.

- 많은 사람이 공통으로 품고 있지만, 각자는 혼자만의 것이라 여기는 욕망을 찾는다.
- 판별 문장: "나만 그런 줄 알았는데, 남들도 그런 거였어."
- 기획안에 '이 이야기가 건드리는 공통분모'를 한 줄로 적는다.

## 3단계. 인물 — 매력 공식으로 설계한다

- **매력 = 동경심 + 동질감**
  - 동경심: 시청자가 닮고 싶은 능력·태도·신념.
  - 동질감: 그 대단한 인물이 알고 보니 나와 비슷한 약점·일상을 가졌다는 깨달음.
- **치명적 매력 = 동경심 + 동정심**
  - 동정심은 감정적 유대를 가장 강하게 만든다. 주인공의 처지가 안타까워 잘되길 바라게 되는 마음이고, 그 응원이 시청률로 이어진다.
  - 흥행작에는 대개 고난에 처한 주인공이 있다.

인물마다 아래 표를 채운다.

| 항목 | 내용 |
|---|---|
| 동경 요소 | |
| 동질 요소 | |
| 동정 요소(처지·고난) | |
| 욕망(겉) / 결핍(속) | |
| 주제와의 관계 | |

주의: 동정심만 있고 동경심이 없으면 '불쌍한 사람'에 그친다. 고난 속에서도 스스로 움직이는 장면을 반드시 넣는다.

## 4단계. 구조와 장면

- 로그라인의 장애물이 회차·막이 바뀔 때마다 커지는지 점검한다.
- 장면마다 세 가지를 적고 쓴다: 이 장면에서 인물이 원하는 것 / 막는 것 / 장면 끝에서 바뀐 것. 바뀐 것이 없으면 합치거나 지운다.
- 대사는 정보 전달보다 욕망의 충돌로 쓴다. 인물이 속마음을 그대로 말하면 고친다.

## 5단계. 대본 형식

```
S#1. 장소 / 시간(낮·밤)

지문: 현재형, 카메라가 볼 수 있는 것만.

인물A    대사
인물B    (짧은 행동 지시) 대사
```

- 기획안 형식: 제목 / 로그라인 / 하이 콘셉트 / 주제 / 기획 의도(공통분모) / 인물표 / 회차별 줄거리.

## 6단계. 퇴고 체크리스트

- [ ] 로그라인 한 문장으로 전체가 설명되는가
- [ ] 주제와 무관한 장면이 없는가
- [ ] 주인공에게 동경·동질·동정 요소가 모두 보이는가
- [ ] 타깃의 공통분모가 첫 회(첫 10분)에 드러나는가
- [ ] 이야기가 현실을 일깨우는 동시에, 현실을 견딜 만하게 해 주는가

## 분석 훈련 — 두 번 보기

사용자가 참고작을 언급하면: 한 번은 즐기고, 한 번은 분석한다. 분석 단계에서 그 작품의 로그라인·주제·하이 콘셉트를 역산해 정리하고, 주인공을 매력 공식 표로 해부해 보여 준다. 좋아하는 작품을 반복해서 보는 것이 가장 확실한 문법 공부다.

## 응용 — 강연·연설·칼럼

극본이 아니어도 이야기 구조가 필요한 글에 쓴다(세바시류 15분 강연, 연설문, 북토크, 페이스북 글).

- 강연의 주인공은 화자 자신이다. 화자의 매력을 공식으로 설계한다: 이룬 것(동경) + 평범했던 출발·실패(동질) + 버텼던 고난(동정).
- 사례 속 인물(예: 골목 소상공인)을 주인공으로 세울 때는 동정심만 자극하는 '불쌍한 사장님' 서사를 피하고, 스스로 판을 바꾸는 장면으로 동경심을 함께 세운다.
- 강연도 로그라인 한 문장과 '끝나고 남을 한 가지(주제)'를 먼저 정한다.
- 문체가 필요하면 golmok-writer 스킬의 문체 규칙과 함께 쓴다.
