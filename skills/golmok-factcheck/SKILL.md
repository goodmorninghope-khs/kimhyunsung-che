# 골목 팩트체크 (golmok-factcheck)

버전: 2026.11.11-1 · 층: 검수(문체 다음, 플레이팅 앞)

저자는 숫자로 설득하고 입장을 분명히 쓴다. 그런 글은 숫자 하나, 직함 하나가 틀리면 논지 전체가 공격받는다. 이 스킬은 발행 직전의 글에서 확인할 수 있는 사실을 모두 뽑아 출처와 대조하고, 판정표 한 장으로 돌려준다.

golmok-writer 13장이 쓰는 사람의 사실 확인 원칙이라면, 이 스킬은 다 쓴 글을 남의 눈으로 다시 검증하는 절차다. 원칙은 13장에 두고 여기서는 절차만 다룬다.

## 세 가지 원칙

1. **기억으로 통과시키지 않는다.** '확인'은 이번에 실제로 열어 본 문서가 있을 때만 붙인다. 열어 보지 못했으면 '확인 불가'다.
2. **글은 고치지 않는다.** 틀린 곳과 고칠 말만 제안한다. 문장, 어조, 비판 수위는 저자와 golmok-writer의 몫이다. 입장이 센 것은 사실 오류가 아니다.
3. **출처를 지어내지 않는다.** 기관 이름, 문서 이름, 기준일, 주소를 댈 수 없으면 근거로 적지 않는다.

## 절차

### 1. 확인할 주장 뽑기

글을 처음부터 끝까지 읽으며 아래에 해당하는 구절을 빠짐없이 번호 붙여 뽑는다.

| 유형 | 볼 것 |
|---|---|
| 숫자 | 값, 단위(만·억·조), %와 %p, 기준 연도, 분모가 무엇인지 |
| 계산 | 증감률, 환산("10%p면 2,700억 원"), 합계. 직접 다시 계산한다 |
| 날짜·시제 | 사건 날짜와 요일, '지난·오는', 시행 예정인지 이미 시행됐는지 |
| 사람·기관 | 이름 표기, 현재 직함, 기관의 정식 명칭과 개편 여부 |
| 직접 인용 | 따옴표 안의 말이 원문과 같은지, 누가 언제 어디서 했는지, 앞뒤 맥락 |
| 제도·법 | 법률과 조항 이름, 발의·통과·시행 중 어느 단계인지 |
| 역사·해외 사례 | 연도, 당사자, 결과. 비교할 때는 닮은 점뿐 아니라 다른 점도 |
| 최상급 | 최초, 최대, 유일, 전국 1위, 꼴찌 |
| 인과 | "~때문에 ~했다"의 근거가 통계인지 추정인지 |
| 저자의 이력·경험 | 글주방과 기존 글에 있는 사실과 맞는지. 창고에 없으면 판정하지 않고 저자에게 묻는다 |

### 2. 급을 매긴다

- **A (틀리면 글이 무너진다)**: 논지를 받치는 핵심 숫자, 실명 인물이나 기업을 비판하는 근거 사실, 실명 직접 인용, 선거·정당·수사·재판에 관한 사실. 반드시 1차 출처로 확인한다.
- **B (틀리면 망신이다)**: 직함, 날짜, 기관 이름, 보조 숫자.
- **C (배경)**: 널리 알려진 일반 사실. 의심스러울 때만 확인한다.

시간이 없으면 A부터 한다. A가 하나라도 '확인 불가'로 남으면 요약에 그 사실을 먼저 적는다.

### 3. 출처와 대조한다

- 검색과 문서 열기 도구를 실제로 쓴다. 검색 결과의 요약 줄이 아니라 원문을 열어 해당 숫자와 문장을 눈으로 확인한다.
- 출처의 순서: 1차 자료(통계청 KOSIS, 부처 보도자료와 통계, 국가법령정보센터, 국회 의안정보시스템, 공정위 의결서, 기업 공시, 연설과 회의록 원문, 책 원문) → 공공기관 보고서 → 언론 보도(서로 다른 두 곳 이상).
- 언론이 다른 언론을 받아 쓴 숫자는 한 곳으로 센다. 맨 처음 어디서 나온 숫자인지 거슬러 올라간다.
- 숫자는 기준 시점을 함께 적는다. 더 새로운 수치가 나와 있으면 '낡음'으로 판정하고 최신치를 적는다.
- 널리 도는 명언일수록 원출처를 의심한다. 누가 한 말로 굳어 있어도 원문을 찾지 못하면 '출처 약함'으로 판정하고 "~의 말로 알려진" 같은 표기를 제안한다. 번역 인용은 원어 문장과 뜻이 같은지 본다.
- golmok-writer 11장 사례 창고의 수치와 다르면 어느 쪽이 맞는지 가려서 적는다.

### 4. 판정한다

| 판정 | 뜻 |
|---|---|
| 확인 | 이번에 연 출처와 일치한다 |
| 수정 필요 | 출처와 다르다. 고칠 말을 적는다 |
| 낡음 | 틀리지는 않았으나 더 새로운 수치가 있다 |
| 출처 약함 | 2차 보도 하나뿐이거나 원출처를 찾지 못했다 |
| 확인 불가 | 근거를 찾지 못했다. 저자에게 출처를 묻는다 |
| 저자 확인 | 저자만 아는 경험·발언·대화다 |

### 5. 글 안의 앞뒤를 맞춘다

- 같은 숫자가 글의 앞과 뒤에서 다르지 않은지 본다.
- 제목과 본문, 본문과 해시태그의 숫자와 이름이 같은지 본다.
- 과거 사실과 기대 효과를 구분한다. 추정이 확정처럼 쓰였으면 '수정 필요'로 올리고 "~로 추산된다" 같은 말을 제안한다.

## 보고 형식

맨 위에 세 줄 요약을 둔다.

- 뽑은 주장 몇 건, 그중 A급 몇 건
- 수정 필요 몇 건, 낡음 몇 건, 확인 불가 몇 건
- 이대로 내도 되는지 한 줄: "A급 모두 확인, 발행 가능" 또는 "A급 2건 미확인, 보류 권고"

그 아래 판정표를 붙인다. '확인'으로 끝난 줄은 뒤로 보내고 고칠 것부터 올린다.

| 번호 | 원문 구절 | 급 | 판정 | 근거 (기관·문서·기준일·주소) | 고칠 말 |
|---|---|---|---|---|---|

모바일에서 읽을 때는 표 대신 고칠 것만 번호 목록으로 먼저 주고, 전체 표는 문서로 붙인다.

## 하지 않을 것

- 문장을 다듬거나 수위를 낮추라고 권하는 일
- 열어 보지 않은 출처로 '확인'을 붙이는 일
- 의견과 해석을 사실 오류로 판정하는 일. 다만 의견이 사실처럼 쓰였으면 표시한다
- 저자의 경험과 대화를 추측으로 판정하는 일

## 넘겨줄 때

- golmok-writer · 판정표의 '고칠 말' · 저자가 고쳐 쓰기를 원할 때. 최신치로 바뀐 사례 창고 수치는 11장 갱신을 함께 제안한다.
- golmok-rebuttal-reader · 사실은 맞지만 반박당하기 쉬운 주장 목록 · 칼럼과 기고처럼 논쟁적인 글일 때.
- 발행물 스킬(jungnang-signal 등) · 출처 표기 · 기관 지면에 실릴 때는 그 지면의 출처 표기 규칙이 앞선다.
